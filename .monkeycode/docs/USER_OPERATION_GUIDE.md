# BarTenderPrinter 使用说明与操作步骤

适用代码版本：`v5.7.91`

本文面向现场操作员、班组长、质量、仓库、工艺/模板维护人员和系统管理员，说明 BarTenderPrinter 的安装、认证、订单与主数据、生产作业、质量返工、出库归档、CSV、打印、追溯和恢复流程。

## 1. 软件用途

BarTenderPrinter 是基于 BarTender COM 接口的标签打印工具，用于包装 MES 场景下按订单、模板和数据源规则执行标签打印。

核心能力：

- 按客户、机型、颜色、订单号管理订单。
- 一个订单支持绑定多个 `.btw` 模板。
- 每个模板独立保存打印机、份数、数据源、锁定、增序/降序、长度校验和本地完整匹配设置。
- 打印前校验启用数据源和值完整性。
- 支持重复校验、本地校验、历史追溯、历史导入和补打印。
- 支持 SQLite 历史存储、JSONL 兼容备份、审计日志和操作员记录。
- 支持 MES 连接、订单查询、组装与包装过站、中心打印作业、追溯查询和断线恢复核查。
- 支持订单状态、生产主数据、号码生命周期、称重与写号任务。
- 支持机身、彩盒、卡通箱和卡板四类标签自动作业。
- 支持质量处置任务、返工、出库、归档修复及 CSV 导入导出。
- 首期使用模拟电子称和模拟写号适配器，页面同时保留真实设备适配接口对应的业务入口。

## 2. 运行环境

### 2.1 系统要求

- Windows 10/11 x64。
- BarTender 2022 R2 Enterprise 或 Automation/Enterprise Automation 版本。
- 使用安装包版本时已内置 .NET 8 运行时。

### 2.2 安装包

安装包命名格式为 `BarTenderPrinter-Setup-v<版本>-win-x64.exe`。

发布列表：`https://github.com/tall-1997/Label-Printer/releases`

## 3. 首次启动

### 3.1 启动软件

1. 运行安装包并完成安装。
2. 从桌面快捷方式或开始菜单启动 `BarTenderPrinter`。
3. 软件启动后会自动连接 BarTender。
4. 如果未安装或未正确注册 BarTender COM，软件会进入离线模式，非打印功能仍可使用。
5. 软件会恢复最近订单、模板、打印机、份数和预览开关；通过 `.btw` 右键菜单启动时优先打开指定模板。

### 3.2 默认账户

软件内置默认账户：

| 项目 | 默认值 |
|---|---|
| 账号 | `superadmin` |
| 密码 | `admin123` |
| 角色 | `Admin` |

首次创建账户文件时使用 `superadmin/admin123`。密码以 PBKDF2-SHA256 加盐摘要保存；登录、补打和历史高风险操作写入审计日志。

### 3.3 手动登录

1. 在历史工具栏点击 `登录`。
2. 输入账号和密码。
3. 点击 `登录`。
4. 登录成功后，操作员和角色会更新。

当前角色权限：

| 角色 | 权限 |
|---|---|
| Admin | 删除历史、补打印审批、全部操作 |
| Supervisor | 补打印审批 |
| Operator | 常规打印操作 |

## 4. 页面结构

### 4.1 左侧导航

左侧有折叠导航栏：

- `打印页面`：选择订单、模板、打印机并执行打印。
- `订单管理`：新增/编辑订单，维护模板和数据源设置。
- `MES 工位`：连接中心服务，执行订单、主数据、生产、质量返工、出库归档、数据交换、打印追溯和恢复操作。

### 4.2 打印页面

打印页面包含：

- 客户、机型、颜色、订单号级联选择。
- 当前生效设置摘要。
- 模板选择。
- 打印机选择。
- 打印份数。
- 动态输入区。
- 打印按钮。
- 历史记录和统计。
- 日志。

### 4.3 订单管理页面

订单管理页面包含：

- 添加订单按钮。
- 客户、机型、颜色、订单号输入框。
- 模板卡片列表。
- 模板路径显示。
- 添加模板、重新读取、删除模板、复制配置。
- 打印机和份数设置。
- 本地完整匹配、重复校验、长度校验。
- 校验数据管理。
- 数据源详细设置表格。
- 保存订单/保存设置按钮。

### 4.4 MES 工位页面

MES 工位页面顶部包含 MES 地址、访问令牌、超时秒数、重试次数和 `保存并连接`。访问令牌仅保留在当前进程配置中；本地连接文件保存地址、超时和重试设置。

页面包含七个一级分组：

- `订单`：查询订单并执行发布、开工、暂停、恢复和关闭。
- `主数据`：创建生产单元、工艺路线、工位和包装单元。
- `生产工位`：组装过站、包装绑定、号码状态、称重规则与称重、写号任务。
- `质量返工`：检验批、检验结果、质量处置任务和返工状态命令。
- `出库归档`：出库单、装箱扫描、确认出库、归档校验及修复。
- `导入导出`：订单/号段 CSV 暂存确认和订单/号段/追溯 CSV 导出。
- `作业与恢复`：MES 打印、统一追溯、待处理重新提交和人工处理。

## 4.5 MES 工位操作

### 4.5.1 连接中心服务

1. 展开左侧导航并打开 `MES 工位`。
2. 输入有效的 HTTP 或 HTTPS MES 地址和部署方提供的访问令牌。
3. 设置 1 至 120 秒超时和 0 至 3 次重试。
4. 点击 `保存并连接`。
5. 页面显示 `MES 已连接` 后开始业务操作；连接成功时客户端自动核对本地待恢复打印作业。

### 4.5.2 组装与包装过站

组装过站需要生产单元 ID、订单 ID、路线 ID、工序 ID 和幂等键。包装过站需要父包装 ID、子包装 ID、父包装当前版本和幂等键。成功后页面生成新的幂等键。

这两类操作依赖中心在线规则校验。连接超时或不可达时，客户端将业务意图保存到本地待处理文件，并显示 `ONLINE_VALIDATION_REQUIRED`；现场应保持原业务对象状态，待中心恢复后重新核查。

### 4.5.3 MES 打印与恢复

1. 点击 `领取打印作业`。
2. 核对标签类型、MES 作业 ID、批次和同步状态。
3. 点击 `使用现有打印流程执行`。
4. 客户端从中心请求快照读取模板路径、打印机、份数和字段值，并通过现有 `PrintJobCoordinator` 执行。
5. 打印完成后客户端回传 `Submitted`、`Failed` 或 `Uncertain`。

回传失败时，本地结果继续保留。点击 `恢复同步` 后，客户端按原始打印幂等键查询中心状态。本地与中心状态一致时记录转为 `Synced`；状态冲突时保留双方快照并转为 `ReviewRequired`，操作员应在 `追溯与核查` 页交由授权人员核查，避免直接重复打印。

### 4.5.4 追溯查询

查询类型支持 `Order`、`Imei`、`SerialNumber`、`Carton` 和 `Pallet`。输入精确业务值后点击 `追溯查询`，响应包含中心保存的生产、过站、包装、打印、审计、质量、返工、出库和归档履历。

### 4.5.5 订单、主数据与号码

1. 在 `订单 > 状态转换` 输入订单 ID、目标状态、预期版本和幂等键。
2. 在 `主数据` 依次创建生产单元、路线、工位和包装单元。
3. 创建生产单元时填写 `号码类型=号码分配ID`，中心将已保留号码分配给生产单元。
4. 在 `生产工位 > 号码状态` 执行冻结、释放或报废，并填写原因码。
5. 使用 `查询历史` 核对号码每次状态变化的操作员、工位和时间。

创建机身包装单元会自动生成机身标签作业；彩盒、卡通箱和卡板达到容量关闭时自动生成对应标签作业。四类作业统一从 `MES 打印` 领取。

### 4.5.6 称重与写号

1. 在 `称重规则` 配置订单、包装类型、重量上下限和单位。
2. 在 `称重` 输入包装单元、模拟重量、单位和设备 ID，提交后查看 `Passed` 或 `Failed`。
3. 在 `写号` 创建任务，填写生产单元和号码分配 ID 集合。
4. 领取任务后提交模拟回读 JSON、结果状态和诊断码。

当前页面固定上报模拟标识。`Uncertain` 写号结果会冻结关联号码和活动生产单元，现场需停止流转并进入核查。真实电子称与厂商写号工具通过既有适配接口后续接入。

### 4.5.7 质量、返工与出库

1. 创建检验批并登记样本生产单元。
2. 提交检验结果；失败结果填写缺陷码、责任工序和备注。
3. 完成失败检验批后查询开放质量处置任务，由授权角色选择 `Release`、`Rework` 或 `Scrap`。
4. 返工流程按创建、审批、激活、返工路线过站、完成顺序执行。
5. 出库流程按创建出库单、扫描已关闭卡通箱、核对计划数量、确认出库顺序执行。

质量冻结中的生产单元或包装层级会阻止后续出库。放行处置恢复原状态，返工处置关联返工单。

### 4.5.8 归档、CSV 与操作恢复

1. 已关闭订单可创建归档；点击 `查询并校验归档` 核对 SHA-256 摘要。
2. 摘要异常时查询修复任务，由归档授权角色执行 `修复并重建归档`，原归档持续保留。
3. CSV 导入选择 `orders` 或 `number-ranges`，先选择文件并查看逐行错误，再确认原子导入。
4. CSV 导出支持订单、号段和追溯数据，结果根据会话角色脱敏。
5. 在 `作业与恢复 > 操作恢复` 刷新待处理记录，可按原幂等键重新提交，或填写核查说明后转人工处理。

CSV 文件使用 UTF-8 编码且大小不超过 10 MB。存在逐行错误的批次无法确认。

## 5. 订单管理操作

## 5.1 新增订单

1. 打开 `订单管理` 页面。
2. 点击 `添加订单`。
3. 输入或选择客户。
4. 输入或选择机型。
5. 输入或选择颜色。
6. 输入订单号。
7. 点击 `添加模板`，选择一个或多个 `.btw` 模板。
8. 对每个模板配置数据源、校验、锁定、步长、打印机和份数。
9. 点击右上角 `保存订单`。

说明：

- 客户、机型、颜色、订单号支持级联输入。
- 选择已有客户后，机型候选只显示该客户下已有机型。
- 选择已有机型后，颜色候选只显示该客户 + 机型下已有颜色。
- 选择已有颜色后，订单号候选只显示该客户 + 机型 + 颜色下已有订单号。
- 输入不存在的客户、机型、颜色或订单号，会按新增订单数据处理。

## 5.2 编辑已有订单

1. 打开 `订单管理` 页面。
2. 依次选择客户、机型、颜色。
3. 在订单号下拉框选择已有订单号。
4. 软件会自动进入该订单编辑状态。
5. 修改模板或数据源设置。
6. 点击右上角 `保存设置`。

## 5.3 订单唯一性

订单以以下四项作为唯一业务组合：

- 客户
- 机型
- 颜色
- 订单号

相同订单号可以存在于不同客户、机型或颜色下。

## 6. 模板管理

### 6.1 添加模板

1. 在订单管理页点击 `添加模板`。
2. 选择 `.btw` 模板文件。
3. 软件会自动读取模板数据源。
4. 模板卡片会显示已启用数据源数量和总数据源数量。

### 6.2 重新读取模板数据源

当模板文件发生变化时：

1. 选择模板卡片。
2. 点击 `重新读取`。
3. 软件会重新获取模板中的命名数据源。
4. 同名字段设置会保留。
5. 新字段会自动加入。
6. 模板卡片数量会立即刷新。

### 6.3 删除模板

方式一：

1. 选中模板卡片。
2. 点击 `删除模板`。
3. 确认删除。

方式二：

1. 右键模板卡片。
2. 点击 `删除此模板`。
3. 确认删除。

说明：

- 删除模板只会从订单中移除模板引用。
- 外部 `.btw` 模板文件不会被删除。

### 6.4 复制模板配置

用于多模板订单快速复用设置：

1. 选中已配置好的模板卡片。
2. 点击 `复制配置`。
3. 确认复制到其他模板。
4. 软件会复制数据源、校验、长度、锁定、步长、打印机和份数设置。

## 7. 数据源详细设置

数据源详细设置表格包含：

| 列 | 说明 |
|---|---|
| 使用 | 是否启用该数据源参与打印 |
| 字段名 | BarTender 模板中的命名数据源 |
| 锁定 | 点击锁图标启用或关闭锁定 |
| 步长 | 正数增序，负数降序，0 为固定锁定 |
| 锁定后输入值 | 锁定字段的当前值或待打印值 |
| 长度 | 单字段长度校验规则 |

### 7.1 全选和反选

- 勾选 `全选数据源`：启用全部数据源。
- 取消 `全选数据源`：取消全部数据源。
- 点击 `反选数据源`：反转每个数据源的启用状态。

### 7.2 锁定字段

1. 在数据源行点击锁图标。
2. 该行进入锁定状态。
3. `步长` 可编辑。
4. `锁定后输入值` 可编辑。

### 7.3 步长规则

| 步长 | 含义 |
|---|---|
| `0` | 固定锁定，不增不减 |
| 正数 | 每次打印后递增 |
| 负数 | 每次打印后递减 |

示例：

- `1`：`AC001` → `AC002`
- `-1`：`AC002` → `AC001`
- `0`：保持当前值不变

### 7.4 关闭锁定

如果步长不是 `0`，关闭锁定时软件会提示：

`当前步长为 X，关闭锁定将恢复默认步长 0。是否确认关闭？`

选择 `是`：关闭锁定并恢复步长为 `0`。

选择 `否`：保留锁定状态和原步长。

### 7.5 锁定增序值恢复

对于增序锁定字段：

- 打印完成后软件会保存下一条待打印值。
- 切换模板后再切回，软件会自动检查该值是否已在当前客户 + 机型 + 颜色 + 订单号 + 模板历史中打印过。
- 如果已打印，会继续按步长推进到下一条未打印值。

示例：

1. 当前锁定增序值为 `1`。
2. 打印完成后下一条应为 `2`。
3. 切换模板后再切回。
4. 如果 `1` 已打印，软件会自动显示 `2`。

## 8. 校验设置

### 8.1 重复校验

重复校验用于防止同一数据重复打印。

规则：

- 只检查成功打印记录。
- 失败记录不会进入重复索引。
- 补打印成功记录会进入历史，但补打印自身不会阻止补打印流程。

### 8.2 长度校验

支持两种长度规则：

- 全局长度：所有未设置单独长度的数据源使用同一长度。
- 单项长度：指定字段使用独立长度。

### 8.3 本地完整匹配

用于校验输入值必须存在于本地导入数据中。

支持文件：

- CSV
- Excel
- TXT

操作步骤：

1. 在订单管理页选中模板。
2. 点击 `选择校验数据`。
3. 选择 CSV、Excel 或 TXT 文件。
4. 如果文件有多列，选择用于校验的列。
5. 软件默认勾选当前模板的全部启用数据源使用校验数据。
6. 在数据源详细设置中按需取消字段的 `使用校验数据`。
7. 软件显示导入统计。
8. 勾选 `本地完整匹配`。

导入统计包含：

- 总行数
- 去重后数量
- 重复数
- 空值数

### 8.4 管理校验数据

点击 `管理校验` 可以查看、替换或清除当前模板校验数据。

每个模板保存一份校验数据快照，每个启用数据源独立保存 `使用校验数据` 选项。打印和补打印只检查已启用且勾选该选项的字段。

如果尚未导入校验数据，软件会提示先选择校验数据文件。

## 9. 打印操作

### 9.1 选择订单

1. 打开 `打印页面`。
2. 从顶部依次选择客户、机型、颜色、订单号。
3. 软件加载该订单绑定模板和配置。
4. 顶部显示当前生效设置摘要。

当前生效设置摘要包含：

- 订单
- 模板
- 打印机
- 份数
- 启用字段数量
- 本地校验、重复校验、长度校验状态

### 9.2 选择模板

如果订单绑定多个模板：

1. 在模板下拉框选择目标模板。
2. 软件加载该模板独立的数据源和校验配置。

### 9.3 输入数据

1. 在动态输入区输入或扫码。
2. 按回车跳转到下一个可编辑输入框。
3. 最后一个输入框按回车会触发打印。

锁定字段说明：

- 固定锁定字段不可编辑。
- 增序或降序字段打印后自动更新。
- 未锁定字段打印后自动清空。

### 9.4 静默打印

字段和校验数据通过检查后，软件会将作业加入本地 FIFO 队列，立即推进增降序、清空普通输入并聚焦下一次扫码。后台 BarTender STA 线程按入队顺序隐藏窗口提交作业，遇到 Busy 状态会短间隔重试。打印前请在打印页确认订单、模板、打印机、份数和当前生效设置。

### 9.5 标签预览

应用启动时通过独立的 .NET Framework 4.8 x64 宿主检测目标机器安装的 BarTender 2022 R2 `Seagull.BarTender.Print` SDK，并执行 Engine 启停探针。检测成功后显示 `开启预览`；宿主、SDK、架构、版本或依赖异常时显示 `预览不可用`，鼠标停留可查看原因。打印后预览只使用当前模板仍存在的历史字段，旧字段会被忽略；无可用动态字段时显示原模板缩略图。预览窗口按图片比例和屏幕工作区自动调整。

## 10. 补打印

### 10.1 补打印权限

补打印需要以下角色之一：

- Admin
- Supervisor

Operator 无补打印审批权限。

### 10.2 补打印步骤

1. 在历史记录中选择一条记录。
2. 点击 `补打印选中项`。
3. 选择本次补打印打印机。
4. 确认补打印。

### 10.3 模板版本差异提示

如果历史记录中的模板版本与当前模板文件版本不一致，软件会提示风险。

继续补打印前请确认：

- 模板版面是否仍兼容。
- 字段是否仍一致。
- 补打印内容是否符合现场要求。

## 11. 历史记录

历史记录页支持：

- 搜索
- 精确搜索
- 状态筛选
- 日期筛选
- 分页
- 导入历史字段
- 补打印
- 删除历史
- 导出 CSV

### 11.1 搜索

可以按以下内容搜索：

- 字段名
- 字段值
- 模板
- 时间
- 状态
- 打印机
- 份数

### 11.2 高级筛选

支持按状态筛选：

- PASS
- FAIL
- REPRINT_PASS
- REPRINT_FAIL

支持按日期筛选，格式：

`yyyy-MM-dd`

### 11.3 分页

使用 `上一页` 和 `下一页` 浏览历史记录。

### 11.4 导入历史字段

1. 选择历史记录。
2. 点击 `导入`。
3. 选择要导入的字段。
4. 软件写入当前输入框。

对于增序锁定字段，导入后会同步锁定值和增序锁定状态。

### 11.5 排除历史和清空控件

排除历史和清空控件需要 Admin 角色。

排除单条记录：

1. 右键历史记录。
2. 点击 `从历史控件排除此记录`。
3. 阅读高风险提示并确认。

清空当前模板历史控件：

1. 点击 `清空控件`。
2. 核对提示中的活动记录数量。
3. 阅读高风险提示并确认。

以上操作会让记录退出当前显示、搜索、统计、重复校验、预览、导入和补打印调用。SQLite、JSONL 和独立历史副本持续保存原始数据，操作信息会写入审计日志。

## 12. 审计与数据存储

### 12.1 主要数据目录

`%LocalAppData%\BarTenderPrinter`

### 12.2 主要文件

| 文件或目录 | 说明 |
|---|---|
| `config.ini` | 本机通用配置 |
| `orders.json` | 订单和模板绑定配置 |

## 13. 常见问题

### 13.1 BarTender 未连接

处理步骤：

1. 确认已安装 BarTender。
2. 确认版本支持 COM 自动化。
3. 重启 BarTenderPrinter。
4. 仍失败时导出日志交给管理员分析。

### 13.2 模板字段未找到

原因：

- 订单设置中启用了模板不存在的数据源。
- 模板字段被改名或删除。

处理步骤：

1. 进入订单管理。
2. 选中模板。
3. 点击 `重新读取`。
4. 核对数据源启用状态。
5. 保存设置。

### 13.3 数据重复

原因：

- 输入值已在历史成功打印记录中出现。
- 增序锁定值没有推进到下一条。

处理步骤：

1. 检查当前订单和模板是否正确。
2. 检查锁定增序字段值。
3. 切换模板后再切回，软件会自动跳过已打印值。
4. 如仍重复，检查历史记录中是否已有该值。

### 13.4 本地完整匹配失败

原因：

- 输入值不在导入的校验数据中。
- 校验数据绑定了错误字段。
- 导入列选择错误。

处理步骤：

1. 进入订单管理。
2. 选中模板。
3. 点击 `管理校验` 查看校验数据。
4. 必要时重新选择校验数据。
5. 确认绑定字段正确。

### 13.5 补打印被阻止

可能原因：

- 当前角色不是 Admin 或 Supervisor。
- 历史模板文件不存在。
- 历史模板版本与当前模板版本不同，需要确认风险。

## 14. 推荐现场流程

### 14.1 管理员准备

1. 安装 BarTender。
2. 安装 BarTenderPrinter。
3. 准备 `.btw` 模板。
4. 在订单管理中创建订单。
5. 添加模板。
6. 重新读取数据源。
7. 配置锁定、步长、长度、校验数据。
8. 保存订单。
9. 做一次测试打印。

### 14.2 操作员日常打印

1. 打开软件。
2. 确认操作员账户。
3. 在打印页选择客户、机型、颜色、订单号。
4. 确认当前生效设置摘要。
5. 输入或扫码数据。
6. 数据通过校验后自动静默打印。
7. 查看历史和日志确认结果。

### 14.3 异常处理

1. 不确定模板是否正确时，先停止打印。
2. 进入订单管理重新读取数据源。
3. 核对字段、锁定、步长、长度和校验数据。
4. 保存设置。
5. 使用测试数据验证。
6. 再恢复生产打印。

## 15. 维护建议

- 定期备份 `%LocalAppData%\BarTenderPrinter`。
- 模板变更后必须点击 `重新读取` 并保存订单设置。
- 补打印必须填写真实原因。
- 不建议多人同时编辑同一台电脑上的订单配置。
- 首次登录使用 `superadmin/admin123`；账户文件中的密码以 PBKDF2-SHA256 加盐摘要保存。
- HASP/Sentinel 商业授权、加密狗驱动和许可证服务器不属于本项目操作范围。
- MES Bearer 令牌由部署管理员提供，操作员不得写入模板、CSV 或日志。
- 定期导出历史记录和日志用于追溯。
