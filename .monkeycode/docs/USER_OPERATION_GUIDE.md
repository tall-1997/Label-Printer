# BarTenderPrinter 使用说明与操作步骤

适用版本：`v5.7.61`

本文面向现场操作员、班组长、工艺/模板维护人员和系统管理员，说明 BarTenderPrinter 的安装、登录、订单管理、模板配置、数据源设置、打印、补打印、历史追溯和日常维护流程。

## 1. 软件用途

BarTenderPrinter 是基于 BarTender COM 接口的标签打印工具，用于包装 MES 场景下按订单、模板和数据源规则执行标签打印。

核心能力：

- 按客户、机型、颜色、订单号管理订单。
- 一个订单支持绑定多个 `.btw` 模板。
- 每个模板独立保存打印机、份数、数据源、锁定、增序/降序、长度校验和本地完整匹配设置。
- 打印前校验启用数据源和值完整性。
- 支持重复校验、本地校验、历史追溯、历史导入和补打印。
- 支持 SQLite 历史存储、JSONL 兼容备份、审计日志和操作员记录。

## 2. 运行环境

- Windows 10/11 x64。
- BarTender 2022 R2 Enterprise 或 Automation/Enterprise Automation 版本。
- 使用安装包版本时已内置 .NET 8 运行时。

## 3. 首次启动

### 3.1 启动软件

1. 运行安装包并完成安装。
2. 从桌面快捷方式或开始菜单启动 `BarTenderPrinter`。
3. 软件启动后会自动连接 BarTender。
4. 如果未安装或未正确注册 BarTender COM，软件会进入离线模式，非打印功能仍可使用。

### 3.2 默认账户

软件内置默认账户：

| 项目 | 默认值 |
|---|---|
| 账号 | `superadmin` |
| 密码 | `admin` |
| 角色 | `Admin` |

启动后默认静默登录 `superadmin/admin`。

### 3.3 手动登录

1. 在历史工具栏点击 `登录`。
2. 输入账号和密码。
3. 点击 `登录`。
4. 登录成功后，操作员和角色会更新。

当前角色权限：

| 角色 | 权限 |
|---|---|
| Admin | 删除历史、补打印审批、全部操作 |
| Supervisor | 补打印审批 |
| Operator | 常规打印操作 |

## 5. 订单管理操作

## 5.1 新增订单

1. 打开 `订单管理` 页面。
2. 点击 `添加订单`。
3. 输入或选择客户。
4. 输入或选择机型。
5. 输入或选择颜色。
6. 输入订单号。
7. 点击 `添加模板`，选择一个或多个 `.btw` 模板。
8. 对每个模板配置数据源、校验、锁定、步长、打印机和份数。
9. 点击右上角 `保存订单`。

说明：

- 客户、机型、颜色、订单号支持级联输入。
- 选择已有客户后，机型候选只显示该客户下已有机型。
- 选择已有机型后，颜色候选只显示该客户 + 机型下已有颜色。
- 选择已有颜色后，订单号候选只显示该客户 + 机型 + 颜色下已有订单号。
- 输入不存在的客户、机型、颜色或订单号，会按新增订单数据处理。

## 5.2 编辑已有订单

1. 打开 `订单管理` 页面。
2. 依次选择客户、机型、颜色。
3. 在订单号下拉框选择已有订单号。
4. 软件会自动进入该订单编辑状态。
5. 修改模板或数据源设置。
6. 点击右上角 `保存设置`。

## 5.3 订单唯一性

订单以以下四项作为唯一业务组合：

- 客户
- 机型
- 颜色
- 订单号

相同订单号可以存在于不同客户、机型或颜色下。

## 6. 模板管理

### 6.1 添加模板

1. 在订单管理页点击 `添加模板`。
2. 选择 `.btw` 模板文件。
3. 软件会自动读取模板数据源。
4. 模板卡片会显示已启用数据源数量和总数据源数量。

### 6.2 重新读取模板数据源

当模板文件发生变化时：

1. 选择模板卡片。
2. 点击 `重新读取`。
3. 软件会重新获取模板中的命名数据源。
4. 同名字段设置会保留。
5. 新字段会自动加入。
6. 模板卡片数量会立即刷新。

### 6.3 删除模板

方式一：

1. 选中模板卡片。
2. 点击 `删除模板`。
3. 确认删除。

方式二：

1. 右键模板卡片。
2. 点击 `删除此模板`。
3. 确认删除。

说明：

- 删除模板只会从订单中移除模板引用。
- 外部 `.btw` 模板文件不会被删除。

### 6.4 复制模板配置

用于多模板订单快速复用设置：

1. 选中已配置好的模板卡片。
2. 点击 `复制配置`。
3. 确认复制到其他模板。
4. 软件会复制数据源、校验、长度、锁定、步长、打印机和份数设置。

## 7. 数据源详细设置

数据源详细设置表格包含：

| 列 | 说明 |
|---|---|
| 使用 | 是否启用该数据源参与打印 |
| 字段名 | BarTender 模板中的命名数据源 |
| 锁定 | 点击锁图标启用或关闭锁定 |
| 步长 | 正数增序，负数降序，0 为固定锁定 |
| 锁定后输入值 | 锁定字段的当前值或待打印值 |
| 长度 | 单字段长度校验规则 |

### 7.1 全选和反选

- 勾选 `全选数据源`：启用全部数据源。
- 取消 `全选数据源`：取消全部数据源。
- 点击 `反选数据源`：反转每个数据源的启用状态。

### 7.2 锁定字段

1. 在数据源行点击锁图标。
2. 该行进入锁定状态。
3. `步长` 可编辑。
4. `锁定后输入值` 可编辑。

### 7.3 步长规则

| 步长 | 含义 |
|---|---|
| `0` | 固定锁定，不增不减 |
| 正数 | 每次打印后递增 |
| 负数 | 每次打印后递减 |

示例：

- `1`：`AC001` → `AC002`
- `-1`：`AC002` → `AC001`
- `0`：保持当前值不变

### 7.4 关闭锁定

如果步长不是 `0`，关闭锁定时软件会提示：

`当前步长为 X，关闭锁定将恢复默认步长 0。是否确认关闭？`

选择 `是`：关闭锁定并恢复步长为 `0`。

选择 `否`：保留锁定状态和原步长。

### 7.5 锁定增序值恢复

对于增序锁定字段：

- 打印完成后软件会保存下一条待打印值。
- 切换模板后再切回，软件会自动检查该值是否已在当前客户 + 机型 + 颜色 + 订单号 + 模板历史中打印过。
- 如果已打印，会继续按步长推进到下一条未打印值。

示例：

1. 当前锁定增序值为 `1`。
2. 打印完成后下一条应为 `2`。
3. 切换模板后再切回。
4. 如果 `1` 已打印，软件会自动显示 `2`。

## 8. 校验设置

### 8.1 重复校验

重复校验用于防止同一数据重复打印。

规则：

- 只检查成功打印记录。
- 失败记录不会进入重复索引。
- 补打印成功记录会进入历史，但补打印自身不会阻止补打印流程。

### 8.2 长度校验

支持两种长度规则：

- 全局长度：所有未设置单独长度的数据源使用同一长度。
- 单项长度：指定字段使用独立长度。

### 8.3 本地完整匹配

用于校验输入值必须存在于本地导入数据中。

支持文件：

- CSV
- Excel
- TXT

操作步骤：

1. 在订单管理页选中模板。
2. 点击 `选择校验数据`。
3. 选择 CSV、Excel 或 TXT 文件。
4. 如果文件有多列，选择用于校验的列。
5. 选择该列绑定的数据源字段。
6. 软件显示导入统计。
7. 勾选 `本地完整匹配`。

导入统计包含：

- 总行数
- 去重后数量
- 重复数
- 空值数

### 8.4 管理校验数据

点击 `管理校验` 可以查看、替换或清除当前模板校验数据。

如果尚未导入校验数据，软件会提示先选择校验数据文件。

## 9. 打印操作

### 9.1 选择订单

1. 打开 `打印页面`。
2. 从顶部依次选择客户、机型、颜色、订单号。
3. 软件加载该订单绑定模板和配置。
4. 顶部显示当前生效设置摘要。

当前生效设置摘要包含：

- 订单
- 模板
- 打印机
- 份数
- 启用字段数量
- 本地校验、重复校验、长度校验状态

### 9.2 选择模板

如果订单绑定多个模板：

1. 在模板下拉框选择目标模板。
2. 软件加载该模板独立的数据源和校验配置。

### 9.3 输入数据

1. 在动态输入区输入或扫码。
2. 按回车跳转到下一个可编辑输入框。
3. 最后一个输入框按回车会触发打印。

锁定字段说明：

- 固定锁定字段不可编辑。
- 增序或降序字段打印后自动更新。
- 未锁定字段打印后自动清空。

### 9.4 静默打印

字段和校验数据通过检查后，软件会隐藏 BarTender 打印状态窗口，将作业直接提交到打印队列并立即恢复输入。打印前请在打印页确认订单、模板、打印机、份数和当前生效设置。

## 10. 补打印

### 10.1 补打印权限

补打印需要以下角色之一：

- Admin
- Supervisor

Operator 无补打印审批权限。

### 10.2 补打印步骤

1. 在历史记录中选择一条记录。
2. 点击 `补打印选中项`。
3. 选择本次补打印打印机。
4. 确认补打印。

### 10.3 模板版本差异提示

如果历史记录中的模板版本与当前模板文件版本不一致，软件会提示风险。

继续补打印前请确认：

- 模板版面是否仍兼容。
- 字段是否仍一致。
- 补打印内容是否符合现场要求。

## 11. 历史记录

历史记录页支持：

- 搜索
- 精确搜索
- 状态筛选
- 日期筛选
- 分页
- 导入历史字段
- 补打印
- 删除历史
- 导出 CSV

### 11.1 搜索

可以按以下内容搜索：

- 字段名
- 字段值
- 模板
- 时间
- 状态
- 打印机
- 份数

### 11.2 高级筛选

支持按状态筛选：

- PASS
- FAIL
- REPRINT_PASS
- REPRINT_FAIL

支持按日期筛选，格式：

`yyyy-MM-dd`

### 11.3 分页

使用 `上一页` 和 `下一页` 浏览历史记录。

### 11.4 导入历史字段

1. 选择历史记录。
2. 点击 `导入`。
3. 选择要导入的字段。
4. 软件写入当前输入框。

对于增序锁定字段，导入后会同步锁定值和增序锁定状态。

### 11.5 删除历史

删除历史需要 Admin 角色。

操作步骤：

1. 右键历史记录。
2. 点击 `删除此条记录`。
3. 确认删除。

删除操作会写入审计日志。

## 12. 审计与数据存储

### 12.1 主要数据目录

数据保存目录：

`%LocalAppData%\BarTenderPrinter`

### 12.2 主要文件

| 文件或目录 | 说明 |
|---|---|
| `config.ini` | 本机通用配置 |
| `orders.json` | 订单和模板绑定配置 |
| `template_settings.json` | 普通模板设置 |
| `print_records.db` | SQLite 历史主存储 |
| `print_records.jsonl` | 历史兼容备份 |
| `print_records.csv` | 旧版历史兼容文件 |
| `validation-data/` | 本地校验数据快照 |

### 12.3 审计日志

以下操作会写入审计日志：

- 登录
- 补打印
- 删除历史

审计日志采用哈希链方式记录，用于发现日志被篡改的风险。

## 13. 常见问题

### 13.1 BarTender 未连接

处理步骤：

1. 确认已安装 BarTender。
2. 确认版本支持 COM 自动化。
3. 重启 BarTenderPrinter。
4. 仍失败时导出日志交给管理员分析。

### 13.2 模板字段未找到

原因：

- 订单设置中启用了模板不存在的数据源。
- 模板字段被改名或删除。

处理步骤：

1. 进入订单管理。
2. 选中模板。
3. 点击 `重新读取`。
4. 核对数据源启用状态。
5. 保存设置。

### 13.3 数据重复

原因：

- 输入值已在历史成功打印记录中出现。
- 增序锁定值没有推进到下一条。

处理步骤：

1. 检查当前订单和模板是否正确。
2. 检查锁定增序字段值。
3. 切换模板后再切回，软件会自动跳过已打印值。
4. 如仍重复，检查历史记录中是否已有该值。

### 13.4 本地完整匹配失败

原因：

- 输入值不在导入的校验数据中。
- 校验数据绑定了错误字段。
- 导入列选择错误。

处理步骤：

1. 进入订单管理。
2. 选中模板。
3. 点击 `管理校验` 查看校验数据。
4. 必要时重新选择校验数据。
5. 确认绑定字段正确。

### 13.5 补打印被阻止

可能原因：

- 当前角色不是 Admin 或 Supervisor。
- 历史模板文件不存在。
- 历史模板版本与当前模板版本不同，需要确认风险。

## 14. 推荐现场流程

### 14.1 管理员准备

1. 安装 BarTender。
2. 安装 BarTenderPrinter。
3. 准备 `.btw` 模板。
4. 在订单管理中创建订单。
5. 添加模板。
6. 重新读取数据源。
7. 配置锁定、步长、长度、校验数据。
8. 保存订单。
9. 做一次测试打印。

### 14.2 操作员日常打印

1. 打开软件。
2. 确认操作员账户。
3. 在打印页选择客户、机型、颜色、订单号。
4. 确认当前生效设置摘要。
5. 输入或扫码数据。
6. 数据通过校验后自动静默打印。
7. 查看历史和日志确认结果。

### 14.3 异常处理

1. 不确定模板是否正确时，先停止打印。
2. 进入订单管理重新读取数据源。
3. 核对字段、锁定、步长、长度和校验数据。
4. 保存设置。
5. 使用测试数据验证。
6. 再恢复生产打印。

## 15. 维护建议

- 定期备份 `%LocalAppData%\BarTenderPrinter`。
- 模板变更后必须点击 `重新读取` 并保存订单设置。
- 补打印必须填写真实原因。
- 不建议多人同时编辑同一台电脑上的订单配置。
- 生产环境中建议修改默认 `superadmin/admin` 密码。
- 定期导出历史记录和日志用于追溯。
