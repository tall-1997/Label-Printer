# BarTenderPrinter 用户操作指南

适用代码版本：`v5.7.94`

## 1. 软件用途

BarTenderPrinter 用于 Windows 环境下的标签打印、订单模板管理、字段校验、标签预览、历史查询、受控补打印和多电脑端到端加密同步。

## 2. 运行要求

- Windows 10/11 x64。
- BarTender 2022 R2 Automation 或 Enterprise x64。
- 可访问的 `.btw` 模板文件和 Windows 打印机。
- 同步功能需要坚果云账号、第三方应用密码和可访问 `https://dav.jianguoyun.com/dav/` 的 HTTPS 网络。

## 3. 页面导航

左上角菜单包含三个页面：

- `打印页面`：选择订单、模板和打印机，输入字段并执行打印。
- `订单管理`：维护客户、机型、颜色、订单号及模板配置。
- `同步中心`：创建或加入协作空间、立即同步、管理设备与直连、处理冲突和导出诊断。

## 4. 订单与模板

1. 打开 `订单管理`。
2. 点击 `添加订单`，填写客户、机型、颜色和唯一订单号。
3. 选择一个或多个 `.btw` 模板。
4. 为每个模板配置打印机、份数、数据源、锁定、增降序和长度规则。
5. 按需选择 CSV、Excel 或 TXT 校验数据，并指定参与校验的列和字段。
6. 保存订单设置。

模板在当前电脑使用绝对路径。同步会将订单和模板设置中的路径转换为模板 SHA-256 逻辑引用；成员电脑验证并缓存模板后映射到本机 `template-cache`。外部模板发生变化时，软件会提示使用外部新版或保留当前归档配置。

## 5. 普通打印

1. 打开 `打印页面`。
2. 依次选择客户、机型、颜色、订单号和模板。
3. 核对打印机、份数、校验开关和预览开关。
4. 扫码或输入各字段。
5. 在最后一个字段按回车，或点击 `打印`。
6. 等待状态栏显示提交结果。

打印请求会先写入本地可靠性账本。状态说明：

- `PRINT_PASS`：打印提交和历史保存成功。
- `PRINT_FAIL`：打印提交失败。
- `PRINT_UNCERTAIN`：外部提交结果无法确认，需要核查打印机和 BarTender 历史。

`PRINT_UNCERTAIN` 状态下应先人工核查实际标签，再决定后续操作。

## 6. 数据源规则

- 普通锁定字段在打印后保留原值。
- 正步长字段打印后自动递增。
- 负步长字段打印后自动递减。
- 未锁定字段打印后自动清空。
- 长度校验可使用全局长度或字段独立长度。
- 重复校验会检查当前模板历史中的活动记录。
- 本地数据校验会检查导入快照中的允许值。

## 7. 标签预览

启用预览后，软件通过独立宿主加载当前模板和字段快照并导出 PNG。预览宿主异常或超时时，主打印应用保持运行。

预览缓存基于模板内容和字段快照。模板或字段变化后会生成新预览。

## 8. 历史记录

历史页支持：

- 按字段、模板、时间、状态、打印机、份数和订单搜索。
- 将历史字段导入当前输入框。
- 导出当前筛选结果为 CSV。
- 排除错误记录，使其退出界面、统计和重复校验。
- 查看今日打印数和总打印数。

排除操作保留底层历史与审计信息。

## 9. 补打印

1. 使用 Supervisor 或 Admin 账户登录。
2. 在历史中选择目标记录。
3. 点击 `补打印选中项`。
4. 核对模板、打印机和份数。
5. 填写明确的补打印原因。
6. 模板版本发生变化时再次确认。
7. 提交并核对结果。

每次补打印保存原作业 ID、审批 ID、原因、操作员和递增序号。补打印直接使用历史字段快照，并保留模板版本确认步骤。

## 10. 创建或加入协作空间

第一台电脑创建空间：

1. 在坚果云 `账户信息 > 安全选项 > 第三方应用管理` 生成应用密码。
2. 打开 `同步中心`，填写固定地址 `https://dav.jianguoyun.com/dav/`、坚果云邮箱、应用密码、空间名称和共享密码。
3. 点击 `测试 WebDAV`，确认目录读写正常。
4. 点击 `创建协作空间`。
5. 点击 `导出连接文件`，保存扩展名为 `.btpsync` 的文件并再次输入共享密码。

成员电脑加入空间：

1. 从管理员处取得 `.btpsync` 和共享密码，两者使用独立安全渠道传递。
2. 打开 `同步中心`，点击 `导入连接文件`。
3. 选择文件并输入共享密码。
4. 导入成功后点击 `立即同步`，等待订单、模板设置、逐条历史、远端作业事件和模板缓存完成更新。
5. 为当前电脑选择可用打印机并核对本地路径。

`.btpsync` 内的 WebDAV 凭据和空间数据密钥经过共享密码加密，文件本身不保存共享密码。导入成功后，配置由当前 Windows 用户的 DPAPI 保存；其他 Windows 用户无法直接解密该配置。

## 11. 同步中心

顶部状态卡显示工作空间、当前设备、活动通道、最后成功时间、待上传事件和冲突数量。页面提供：

- `立即同步` 和 `取消`：执行或终止当前增量同步。
- `连接设置`：创建、导入、导出和测试 WebDAV。
- `设备与直连`：查看已发布 host、更新时间、地址数量和最近结果。
- `冲突处理`：选择保留本地版本或采用远端版本；逐字段合并入口当前会提示需要差异编辑器。
- `用量与诊断`：查看月度上传、下载和请求计数，导出脱敏诊断。

同步会在应用启动、网络恢复、共享数据保存后约 10 秒以及正常退出前自动尝试。网络中断时本地打印继续工作，事件保留在 outbox；恢复网络后可等待自动同步或点击 `立即同步`。

## 12. 可选专网直连

1. 确认各电脑位于可互通的局域网、企业专网或 VPN。
2. 在每台电脑勾选 `启用专网直连`，设置 `1024` 到 `65535` 的 TCP 端口。
3. 在 Windows 防火墙中仅为受控网络允许该应用和端口入站。
4. 发布本机端点并在设备列表中测试目标设备。

软件自动选择具备默认路由的有效 host，将 host、端口、优先级、24 小时有效期和 TLS 证书指纹加密发布到 WebDAV。连接时仅尝试已发布且未过期的端点，校验证书指纹和空间身份。直连不可达时本轮同步继续使用 WebDAV；关闭直连后全部数据仍可通过 WebDAV 同步。

## 13. 数据一致性与权威边界

`print_jobs.db` 是当前电脑打印执行的唯一权威账本，负责幂等、防重、`Uncertain` 和崩溃恢复。其他电脑的作业状态只作为远端共享事件保存，用于追溯，不会改变当前电脑的打印执行结论或自动触发补打印。

打印历史按 `RecordId` 逐条同步。订单和全局模板设置出现并发版本差异时进入冲突列表；模板内容以 SHA-256 保存独立版本。处理冲突前应核对订单字段、模板引用和修改电脑。

## 14. 本地数据与恢复

数据保存在 `%LOCALAPPDATA%\BarTenderPrinter`。重要文件包括：

- `orders.json`：订单配置。
- `print_records.db`：打印历史。
- `print_records.jsonl`：历史兼容副本。
- `print_jobs.db`：打印作业账本。
- `history-records`：逐条历史归档。
- `sync-profile.dat`：DPAPI 保护的连接配置。
- `sync.db`：outbox、cursor、conflict、隔离对象、快照基线、设备、用量和同步活动。
- `template-cache`：同步并校验后的 `.btw` 模板。
- `sync-incoming`、`sync-staging`：同步接收和暂存目录。
- `direct-sync-certificates`：DPAPI 保护的直连证书。

程序异常退出后，账本中处于外部提交阶段的作业会恢复为 `Uncertain`。此状态用于提示人工核查，防止自动重复打印。

坚果云远端目录为 `BarTenderPrinterSync/spaces/{space-id}/`，包含空间描述、设备端点、逐设备事件、模板密文、加密快照和加密快照指针。云端业务对象均为 AES-256-GCM v2 密文。首次加入可先恢复最新快照，再拉取后续事件。损坏事件或模板会进入脱敏隔离记录并保留最近有效本地版本；认证失败和同名摘要不一致会显示为阻断状态，频率限制按服务时间或自动退避重试。

## 15. 常见问题

### BarTender 未连接

确认已安装 x64 BarTender 2022 R2，并检查当前 Windows 账户能否直接打开模板。

### 打印机不可用

点击刷新打印机，检查 Windows 打印队列、驱动和打印机在线状态。

### 模板字段为空

确认模板包含命名数据源，并使用 BarTender 保存最新模板。

### 预览不可用

确认安装目录包含 `BarTenderPreviewHost.exe`，并检查 BarTender SDK 与模板访问权限。

### 打印结果待核查

检查打印机队列、BarTender 作业历史和现场标签，完成核查后再执行新的打印或补打印。

### WebDAV 身份验证失败

确认地址保持为 `https://dav.jianguoyun.com/dav/`，账号使用坚果云邮箱，密码使用第三方应用密码。应用密码轮换后，由管理员重新导出并安全分发 `.btpsync`。

### 连接文件无法导入

确认文件扩展名为 `.btpsync`、共享密码准确且文件来自当前协作空间。导入失败不会替换现有本机连接配置。

### 待上传事件持续增加

点击 `测试 WebDAV`，检查网络、账号应用密码、坚果云容量和请求频率。保留 `%LOCALAPPDATA%\BarTenderPrinter\sync.db`，它包含待上传密文队列和 cursor。

### 直连设备不可达

检查两台电脑之间的路由、Windows 防火墙、端口和设备端点有效期。可直接点击 `立即同步` 使用 WebDAV 完成同步。

### 导出诊断

在 `用量与诊断` 中点击 `导出脱敏诊断`。文件包含配置状态、WebDAV host、队列、隔离计数、永久阻断计数和用量等安全摘要，不包含账号密码、共享密码、数据密钥、证书私钥、密文或业务字段值。

## 16. 安全注意

- 使用坚果云第三方应用密码，并在成员撤销或连接文件泄露时轮换应用密码和重新分发连接文件。
- 分开传递 `.btpsync` 与共享密码，避免将两者放入同一邮件、群文件或公开目录。
- 备份前保护 `%LOCALAPPDATA%\BarTenderPrinter` 的访问权限；DPAPI 保护与当前 Windows 用户绑定。
- 只在受控网络启用专网直连，仅开放配置的 TCP 端口，避免公开暴露直连服务。
- `Uncertain` 作业先核查现场打印结果，远端共享作业事件只用于追溯。
