# Requirements Document

## Introduction

本功能统一优化动态标签预览、预览图片显示、逐数据源本地校验和重新启动后的使用状态恢复。

## Glossary

- **动态标签预览**：使用最近成功打印字段值生成的标签图片。
- **当前命名数据源**：当前 BarTender 模板文档中可按名称赋值的数据源集合。
- **逐数据源校验**：每个数据源独立决定输入值是否匹配模板关联的本地校验数据。
- **最近使用状态**：软件退出前正在使用的订单、模板、打印机、份数和预览开关状态。

## Requirements

### Requirement 1: 动态标签预览

**User Story:** AS 操作员, I want 打印后看到包含打印字段值的标签预览, so that 我可以核对实际标签内容。

#### Acceptance Criteria

1. WHEN 系统生成动态标签预览, 系统 SHALL 将历史字段投影到当前模板的命名数据源集合。
2. WHEN 历史记录包含当前模板已经删除或改名的字段, 系统 SHALL 忽略未知字段并继续生成有效字段预览。
3. IF 当前模板没有可应用的历史字段, 系统 SHALL 显示原模板预览。
4. IF 当前模板中已确认存在的字段赋值失败, 系统 SHALL 停止动态预览并显示具体失败原因。
5. WHEN 操作员切换订单, 系统 SHALL 刷新当前订单模板的预览。

### Requirement 2: 预览图片自适应

**User Story:** AS 操作员, I want 标签图片充分利用可用屏幕空间, so that 横向和纵向标签均可清晰查看。

#### Acceptance Criteria

1. WHEN 预览图片加载完成, 系统 SHALL 保持图片纵横比并在预览区域内缩放显示。
2. WHEN 主窗口移动或调整大小, 系统 SHALL 将预览窗口完整限制在当前屏幕工作区内。
3. WHEN 标签图片比例变化, 系统 SHALL 根据图片比例和可用空间调整预览窗口宽度。
4. WHILE 预览窗口显示, 系统 SHALL 为图片保留一致的内容边距。

### Requirement 3: 逐数据源本地校验

**User Story:** AS 操作员, I want 为每个数据源独立选择本地校验, so that 同一份校验数据可以按字段灵活生效。

#### Acceptance Criteria

1. WHEN 操作员导入模板校验数据, 系统 SHALL 默认勾选当前模板所有已启用数据源使用本地校验。
2. WHEN 操作员编辑数据源详细设置, 系统 SHALL 为每个数据源显示“使用校验数据”选项。
3. WHEN 操作员取消某个数据源的校验选项, 系统 SHALL 跳过该数据源的本地完整匹配。
4. WHEN 操作员打印或补打印, 系统 SHALL 对所有已启用逐数据源校验的字段执行完整匹配。
5. WHEN 系统加载旧版单字段绑定配置, 系统 SHALL 将旧目标字段迁移为对应数据源的校验选项。
6. WHEN 系统加载旧版无目标字段配置, 系统 SHALL 为当前已启用数据源恢复校验选项。

### Requirement 4: 最近使用状态恢复

**User Story:** AS 操作员, I want 重新打开软件后恢复上次工作上下文, so that 我可以直接继续打印。

#### Acceptance Criteria

1. WHEN 软件正常退出, 系统 SHALL 保存当前订单、订单模板和普通模板路径。
2. WHEN 软件正常退出, 系统 SHALL 保存当前打印机、份数和预览开关状态。
3. WHEN 软件重新启动且最近订单仍有效, 系统 SHALL 恢复最近订单和订单模板。
4. IF 最近订单不可用且最近普通模板仍有效, 系统 SHALL 恢复最近普通模板。
5. IF 最近保存的打印机当前不可用, 系统 SHALL 保留模板配置并选择可用打印机。
6. IF 最近使用状态文件损坏, 系统 SHALL 使用默认启动状态并记录错误。
