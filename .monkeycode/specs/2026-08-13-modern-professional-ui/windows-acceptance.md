# Windows 验收清单

## 验收环境

- Windows 10 或 Windows 11 x64
- BarTender 2022 R2 和可用的测试打印机
- 一个包含多个命名数据源的 `.btw` 测试模板
- 100%、125%、150% 和 200% 显示缩放配置

## 视觉与 DPI

- [ ] 在每种目标 DPI 下启动应用，确认品牌图标、产品名、版本和 `By---池鱼` 完整可见。
- [ ] 在不同 DPI 的显示器之间移动主窗口，确认图标重新绘制且没有裁切。
- [ ] 切换打印和订单页面，确认左侧导航始终只有一个活动项。
- [ ] 折叠并展开日志区，确认页签、导航和订单工作区始终位于状态栏上方。
- [ ] 打开关于、登录、手动数据源、校验列、全局长度、历史导入和补打印窗口，确认内容完整可见。
- [ ] 打开标签预览，确认窗口间距、宽度和图片比例在 DPI 变化后保持一致。

## 工作流回归

- [ ] 连接 BarTender，确认状态栏通过文字和颜色显示连接状态。
- [ ] 选择订单和模板，输入数据、预览并打印一张标签。
- [ ] 确认成功和失败记录正确显示在历史表格中，并更新今日和累计计数。
- [ ] 对历史记录执行搜索、清空搜索、导出、导入、排除和补打印。
- [ ] 使用部分启用的数据源配置打开设置窗口，确认全选状态与数据源行一致。
- [ ] 连续打开并关闭数据源设置和关于窗口 30 次，确认 Windows 任务管理器中的 GDI 对象数量保持稳定。

## 发布门槛

- [ ] 完成全部检查，界面没有控件裁切、区域重叠、图标残留或工作流回归。
- [ ] 在发布说明中记录 Windows 版本、BarTender 构建版本、打印机型号和已测试的 DPI 配置。
